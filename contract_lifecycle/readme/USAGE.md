1. Abrir un contrato en curso.
2. Usar **Pausar contrato**.
   - Indicar fecha de inicio.
   - Elegir pausa con fecha de reanudación o pausa indefinida.
   - Seleccionar motivo y comentario.
3. El contrato deja de facturar y se crea la línea sucesora o se aplaza la
   línea existente.
4. Si la pausa es indefinida, usar **Reanudar contrato** e indicar la fecha.
5. Si la pausa es planificada, el contrato se reanuda automáticamente al
   terminar la fecha indicada.
6. Para finalizar definitivamente, usar **Terminar contrato** y registrar
   motivo y fecha.

La terminación es definitiva: no se puede reactivar el mismo contrato.
