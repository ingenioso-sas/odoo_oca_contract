Unifies auto-validation (`invoicing_mode` per contract) and adds
email/WhatsApp notification with portal payment link + overdue summary.
Overdue invoices are only reported, never merged (no debt consolidation).
WhatsApp provider is pluggable (`contract.whatsapp.driver`); without a
provider installed the message is logged and cron continues.

Usage
=====

Set the invoicing mode on the contract (or its template):

- Draft: keep invoices in draft (historical behaviour).
- Validate: post the invoice automatically.
- Validate and send: post it and notify the customer by email and/or
  WhatsApp (channel configured per contract), including the portal
  payment link and an overdue-invoices summary.

Optionally enable the overdue digest per contract: a daily cron sends one
digest per contract with the overdue invoices (grace days, resend interval
and max reminders are configurable). Contacts can opt out individually.

The WhatsApp message is built from a `mail.template` (on `account.move`):
each contract (or its template) can select its own in *WhatsApp Template*
(shown when the channel includes WhatsApp); otherwise the default
*Contract invoice: WhatsApp notification* template is used. The rendered
HTML is converted to plain text, keeping links as absolute URLs.
