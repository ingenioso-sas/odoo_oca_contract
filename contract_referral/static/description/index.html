Contract Referral

Descuentos y comisiones por referidos

Configura el descuento del cliente referido y la comisión del cliente referente, con límites de meses y de facturas.

Si el referido tiene una factura vencida, pierde el descuento de forma permanente. La comisión se registra al validar cada factura del referido.

Incluye

  • Descuento porcentual para el referido.
  • Comisión porcentual para el referente.
  • Límite de meses y de facturas.
  • Pérdida del descuento por mora.
  • Registro y consulta de comisiones.
