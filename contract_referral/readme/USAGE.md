1. Crear un referido desde **Contabilidad > Configuración > Contratos >
   Referidos**.
2. Seleccionar:
   - cliente referente;
   - cliente referido;
   - contrato del referido;
   - porcentaje de descuento del referido;
   - porcentaje de comisión del referente;
   - base de la comisión (monto sin impuestos o total);
   - máximo de meses;
   - máximo de facturas.
3. Guardar. El módulo crea automáticamente las reglas de descuento en las
   líneas del contrato del referido.
4. Generar las facturas del contrato.

La factura del referido muestra el descuento y su motivo. Cuando la factura
se valida, se registra una comisión para el referente.

Si el referido tiene una factura vencida, la siguiente factura ya no recibe
el descuento por referido y el beneficio se marca como perdido de forma
permanente.

Las comisiones se consultan en **Contabilidad > Configuración > Contratos >
Comisiones por referido**.
